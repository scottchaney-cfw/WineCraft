Alcohol Procedure

Ebulliometer Calibration

  • Note - run RS test first since the alcohol measurement will be corrected based on value of RS.
  • Unscrew and fill sample vessel with de-ionized water to first indent, or to the water mark in the provided test tube.
  • Fill condensing cylinder with water to measure zero point accurately.
  • Light burner
  • Mercury will advance and then stabilize, backing off a bit to end point.

Run Sample

  • Empty vessel.
  • Replace water in condensing cylinder.
  • Fill with wine sample (again rinsing with sample first) to first indent or to wine mark on provided test tube.
  • Mercury will settle on a value before beginning to climb again so pay attention to where it stabilizes.
  • After noting the value, correct for RS by subtracting out RS*.05

Example:

  • Ebulliometer reading: 15.1%
  • %RS = 2.1
  • Actual alcohol = 15.1 - (2.1 * .05) = 14.995 % v/v
